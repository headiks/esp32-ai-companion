# Эмоции

Таблица параметров: `kDefs` в `core/libcompanion/src/face.cpp`. Этот файл описывает поведение; матрица ниже получена из кода (`cc_allowed`).

| Эмоция | Вид | Когда возникает | Звук |
|---|---|---|---|
| `neutral` | Спокойствие по умолчанию | Нет сильных потребностей | `emotions/neutral.wav`, `neutral_b.wav` |
| `happy` | Подушечки щёк поднимают нижний край, большой зрачок | Высокое счастье и веселье, двойное касание, кормление, поимка светлячка | `emotions/happy.wav`, `happy_b.wav` |
| `very_happy` | Дуги «^ ^», подпрыгивает, искры | Победа в игре, рекорд реакции | `emotions/very_happy.wav`, `very_happy_b.wav` |
| `sad` | Веко поднято у носа, зрачок внизу, слеза | Счастье < 28, сильный голод, проигрыш в крестики-нолики | `emotions/sad.wav`, `sad_b.wav` |
| `angry` | Сильный наклон век, мелкий зрачок, дрожь, пар | Стресс ≥ 82, повторные касания при высоком стрессе | `emotions/angry.wav`, `angry_b.wav` |
| `annoyed` | Плоские полуприкрытые веки, взгляд вбок | Стресс ≥ 65, голод, 5 касаний за 8 с, раннее нажатие в игре | `emotions/annoyed.wav`, `annoyed_b.wav` |
| `surprised` | Круглые глаза, маленький зрачок, «!», резкое раскрытие | Встряхивание, громкий звук | `emotions/surprised.wav`, `surprised_b.wav` |
| `curious` | Один глаз шире, наклон, «?» | Касание, уведомление, долгое бездействие при высоком любопытстве | `emotions/curious.wav`, `curious_b.wav` |
| `thinking` | Взгляд вверх и в сторону, блуждает, точки | Запрос к AI, ход питомца в игре | `emotions/thinking.wav`, `thinking_b.wav` |
| `sleepy` | Тяжёлые веки, медленное моргание | Энергия ≤ 20, сонливость ≥ 75, путь ко сну | `emotions/sleepy.wav`, `sleepy_b.wav` |
| `sleeping` | Видна только нижняя дуга, «z z z» | Энергия ≤ 8, сонливость ≥ 88, экран вниз, бездействие, команда | `emotions/sleeping.wav`, `sleeping_b.wav` |
| `waking_up` | Веки медленно поднимаются, двойные моргания | Касание, поднятие, громкий звук, кнопка PWR | `emotions/waking_up.wav`, `waking_up_b.wav` |
| `scared` | Глаза сведены, зрачки-точки, дрожь | Рывок, громкий звук при стрессе > 40 | `emotions/scared.wav`, `scared_b.wav` |
| `affection` | Мягкие глаза, зрачки-сердца, сердечки | Поглаживание, привязанность ≥ 80 при радости | `emotions/affection.wav`, `affection_b.wav` |
| `bored` | Полузакрытые глаза смотрят вниз и в сторону | Веселье ≤ 25, внимание ≤ 18, бездействие > 5 мин | `emotions/bored.wav`, `bored_b.wav` |
| `attentive` | Широко открыты, зрачок по центру | Хлопок, голос рядом, поднятие устройства | `emotions/attentive.wav`, `attentive_b.wav` |
| `confused` | Разные глаза и зрачки, взгляд мечется | Непонятный текст для AI, встряхивание при стрессе, ничья | `emotions/confused.wav`, `confused_b.wav` |
| `excited` | Широкие, улыбка, большие зрачки, быстро подпрыгивает | Игра, близкий ответ в «Угадай число», конец таймера | `emotions/excited.wav`, `excited_b.wav` |
