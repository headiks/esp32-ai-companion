# Программа для ПК

```bash
pip install -r desktop/requirements.txt
```

```bash
python desktop/src/main.py
```

Работает там, где есть PySide6: Windows, Linux, macOS. BLE обеспечивает bleak, для него нужен адаптер Bluetooth; на Linux нужен BlueZ. Проверена на Windows по USB-протоколу через симулятор; BLE и работа с настоящей платой не проверялись.

| Вкладка | Что делает |
|---|---|
| Подключение | USB-порт, поиск и подключение BLE с PIN, сырые команды JSON |
| Управление | Эмоции, действия питомца, экраны, текст, показатели в реальном времени |
| Звуки | Прослушивание на ПК и на устройстве |
| Настройки | Яркость, громкость, чувствительность, Wi-Fi, AI-сервер, время, сброс |
| Уведомления | Отправка, отметка прочитанным, очистка |
| Диагностика | Состояние устройства, имитация событий |

Внизу окна журнал обмена.

Для проверки без платы запустите `python tools/sim_device.py` и выберите порт `socket://127.0.0.1:7777`.
