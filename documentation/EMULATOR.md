# Эмулятор

```bash
python emulator/main.py
```

При первом запуске ядро собирается автоматически, если есть компилятор C++ или установлен `ziglang`.

Параметры: `--silent` без звука, `--demo` сразу запустить демо, `--storage ПАПКА` своё место хранения состояния, `--screenshot ФАЙЛ --seconds N` снимок окна и выход.

## Что он воспроизводит

Экран, логика, анимации, эмоции, игры и микшер — это тот же C++-код, что в прошивке. Отличается только оболочка: окно вместо дисплея, звуковая карта вместо I2S, файлы вместо NVS.

## Мышь

| Действие | Жест |
|---|---|
| Щелчок | Касание |
| Два щелчка | Двойное касание |
| Удерживать 0,65 с | Длительное касание |
| Перетащить | Свайп |
| Потереть туда-сюда на лице | Поглаживание |
| Правая кнопка на экране, стрелки клавиатуры | Наклон устройства, для лабиринта и орбиты |

## Панель

| Вкладка | Возможности |
|---|---|
| Эмоции | Любая эмоция, обход всех, имитация жестов, текст для автономного AI |
| Питомец | Действия, все показатели, характер |
| Датчики | Встряхивание, рывок, переворот, громкий звук, хлопок, голос. Погода и температура. Заряд, время, ускорение времени, микрофон, звук, громкость, яркость, индикаторы уровня |
| Экраны | Любой экран, отправка уведомлений |
| Звуки | Каждый звук, отключение категорий, прослушать все |
| Устройство | Hardware-in-the-Loop, сырые команды |

Встряхивание, переворот и звуки на вкладке «Датчики» подаются как данные акселерометра и PCM, то есть проходят через настоящие детекторы.

## DEMO MODE

Кнопка сверху показывает сценарий из `emulator/simulation/demo.py`: запуск, пробуждение, эмоции, сон, реакцию на касание, игру, часы, уведомление. Повторное нажатие останавливает демо.

Время суток задаётся на вкладке «Датчики». Чтобы увидеть целые сутки за минуты, выберите ускорение времени.

## Hardware-in-the-Loop

Вкладка «Устройство» подключает плату по USB или BLE. Команды панели уходят на плату, а эмоция и показатели платы повторяются на экране эмулятора. Без платы подключитесь к симулятору:

```bash
python tools/sim_device.py
```

и укажите порт `socket://127.0.0.1:7777`.

## Состояние

Хранится в `emulator/.state`. Чтобы начать заново, удалите эту папку или нажмите «Сбросить всё» в настройках на экране.
