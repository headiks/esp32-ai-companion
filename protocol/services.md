# BLE GATT

Устройство объявляет себя как `Companion-XX:XX:XX` (последние байты MAC).

| Элемент | UUID | Свойства | Назначение |
|---|---|---|---|
| Сервис | `6e7c0001-5a1e-4c6b-9d3f-0c0a1f2b3c4d` | | Сервис компаньона |
| RX | `6e7c0002-5a1e-4c6b-9d3f-0c0a1f2b3c4d` | Write, Write Without Response | Приложение → устройство |
| TX | `6e7c0003-5a1e-4c6b-9d3f-0c0a1f2b3c4d` | Notify | Устройство → приложение |

Строка JSON режется на куски не больше 180 байт. Конец сообщения — символ `\n`: приёмник накапливает байты до него. MTU устройство запрашивает 247.

# USB Serial

USB CDC, строки JSON, разделитель `\n`. Скорость для CDC не важна, клиенты используют 115200. Строки, начинающиеся с `#`, — журнал прошивки, не JSON.

# BLE HID

Одновременно с сервисом компаньона устройство объявляет стандартный сервис HID (`0x1812`) с внешним видом «мышь». Отчёт номер 1, 4 байта: кнопки (биты 0–4), X, Y, колесо. Для него нужно сопряжение.

# Эмулятор и симулятор

`python tools/sim_device.py [порт]` поднимает на `127.0.0.1:7777` TCP-сервер с тем же протоколом и настоящим ядром. Клиенты подключаются к `socket://127.0.0.1:7777`.
