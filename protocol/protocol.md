# Протокол обмена v1

Один протокол для BLE, USB Serial, Wi-Fi и эмулятора. Обрабатывает его один и тот же код: `core/libcompanion/src/protocol.cpp`.

Полный список команд: [commands.json](commands.json). UUID и транспорт: [services.md](services.md).

## Формат

Одна строка UTF-8 JSON на сообщение, разделитель `\n`. Команда — плоский объект, не длиннее 1023 байт. Вложенные объекты отклоняются с ошибкой `bad_json`.

Команда:

```json
{"type": "emotion", "value": "happy", "source": "android", "request_id": 123}
```

Успешный ответ всегда содержит `status`, `emotion`, `energy`, `happiness`, а если команда передала `request_id`, то и его:

```json
{"status": "success", "emotion": "happy", "energy": 82, "happiness": 95, "request_id": 123}
```

Ошибка:

```json
{"status": "error", "error": "bad_value", "message": "unknown emotion", "request_id": 123}
```

## Подтверждения

На каждую команду приходит ровно один ответ с тем же `request_id`. Отправитель сам повторяет запрос, если ответа нет: команды `emotion`, `setting`, `screen` идемпотентны, а `action` и `notify` при повторе выполнятся ещё раз. Значение `emotion` в ответе — текущее, а не запрошенное: переход из сна идёт через `waking_up` и занимает время.

## События

Раз в 2 секунды устройство само шлёт состояние по USB и BLE:

```json
{"event": "state", "emotion": "neutral", "energy": 80, "...": "как в get_state"}
```

Сообщение с полем `event` не является ответом на команду.

## Устройство как контроллер

Телефон показывает большую игру, а устройство служит геймпадом.

```json
{"type": "controller", "value": "start", "mode": "cards", "labels": "As,10h,Kd,2c,7s", "marks": "10000", "title": "Покер"}
```

Режим `pad` показывает кольцо с точкой наклона, режим `cards` показывает карты. Выбор карты наклоном и нажатие приходят событиями, а повтор `start` обновляет карты на экране. Команду `{"type":"controller","value":"ping"}` нужно слать хотя бы раз в 8 секунд, иначе устройство выйдет из режима. Завершение: `"value": "stop"`.

Дополнительные поля `start`: `info` (строка состояния), `hint` (краткая сводка управления внизу экрана), `target` (карта, которую надо побить). `buttons` — подписи кнопок через запятую, которые устройство рисует само: в режиме `cards` три кнопки, они шлют `swipe_down`, `tap` и `swipe_up` (в покере «Пас,Чек,Рейз»); в режиме `pad` одна пилюля удержания («Держи — тормоз»). В режиме `pad` числовой `info` показывается крупно, например скорость в гонках. Без `buttons` всё работает жестами, как раньше. До 6 карт выбор идёт углом наклона напрямую, больше 6 — наклон задаёт скорость прокрутки. Выбор нескольких карт ведёт хост: по `tap` он меняет `marks` и присылает `start` заново.

Устройство шлёт:

```json
{"event": "input", "ax": 0.12, "ay": -0.30}
{"event": "input", "action": "tap", "index": 2}
```

Наклон приходит 20 раз в секунду. Действия: `select`, `tap`, `down`, `up`, `long_press`, `swipe_left`, `swipe_right`, `swipe_up`, `swipe_down`, `shake`. `index` — выбранная карта.

## Версионирование

`hello` возвращает `protocol`. Если команда содержит `"protocol": N` больше версии устройства, придёт `protocol_mismatch`. Новые поля в ответах не меняют версию, клиент обязан игнорировать незнакомые поля.

## Аутентификация

| Транспорт | Правило |
|---|---|
| USB Serial | Доверенный: нужен физический доступ к устройству |
| BLE | Без авторизации доступны только `hello`, `ping`, `auth`. Остальное после `{"type":"auth","pin":"123456"}`. Сброс при отключении |
| Wi-Fi HTTP | Заголовок `X-Companion-Pin` в каждом запросе |

PIN из 6 цифр создаётся при первом запуске и показан на экране «Об устройстве». После 5 неверных попыток авторизация блокируется на минуту.

Ограничения защиты: HTTP не шифруется, используйте его только в доверенной домашней сети; Wi-Fi по умолчанию выключен. В BLE команды шифруются только если телефон выполнил сопряжение (LE Secure Connections). При передаче пароля Wi-Fi через BLE без сопряжения он идёт открытым текстом — для первоначальной настройки надёжнее USB.

## Wi-Fi API

```
POST http://<ip>/api/command
X-Companion-Pin: 123456
Content-Type: application/json

{"type": "notify", "title": "Почта", "text": "Новое письмо", "icon": "mail"}
```
